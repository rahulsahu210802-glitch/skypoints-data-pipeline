# Synthetic daily feeds

These deterministic fixtures simulate the two feeds delivered by the upstream
Source System on `2024-01-15`:

- `members_20240115.psv`: one header and 150 member detail records, with 30
  members for each PDF country (`USA`, `IND`, `PHIL`, `CAN`, and `AU`).
- `redemptions_20240115.json`: the assignment-shaped redemption document for
  member `223457`, containing two transactions.

The member fixture uses the documented pipe-delimited layout including
`Post_Code`. It is generated by `tools/generate_sample_data.py`; rerunning the
generator must reproduce the committed files exactly.

These files are assessment fixtures. In production, the upstream Source System
delivers new dated files to the landing Volume each day.
