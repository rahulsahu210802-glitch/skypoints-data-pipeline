# Synthetic daily feeds

These deterministic fixtures simulate two daily deliveries from the upstream
Source System:

- `members_20240115.psv`: baseline delivery with one header and 150 valid
  member records, containing 30 members for each PDF country (`USA`, `IND`,
  `PHIL`, `CAN`, and `AU`).
- `redemptions_20240115.json`: one array containing assignment-shaped
  redemption documents for four members and nine valid transactions.
- `members_20240116.psv`: next daily full delivery containing the same 150
  valid members plus five deliberately invalid records.
- `redemptions_20240116.json`: next daily feed containing the same nine valid
  transactions plus three deliberately invalid transactions.

The pipeline remains compatible with the PDF's original single-member JSON
object.

The member fixture uses the documented pipe-delimited layout including
`Post_Code`. It is generated by `tools/generate_sample_data.py`; rerunning the
generator must reproduce the committed files exactly.

These files are assessment fixtures. In production, the upstream Source System
delivers new dated files to the landing Volume each day.

The second-day invalid records exercise missing-key, invalid-date, invalid-tier,
unsupported-country, future-transaction-date, and negative-miles rejection
paths without changing the expected valid Gold outputs.
